# Brief a freelance designer

**For:** an email to a designer. Attach or link [`../14-designer-brief.md`](../14-designer-brief.md), [`../11-design-contract.md`](../11-design-contract.md), [`../design-tokens/`](../design-tokens/) and [`../screenshots/`](../screenshots/README.md).

```text
Subject: Website template for independent hotels: brief

Hello [name],

We run a managed website service for independent hotels in France. Every hotel's site is built
from the same set of blocks (header, hero, rooms, offers, FAQ, contact...); a "template" gives
them a look. We have three templates (classic, modern, dark) and want [one / two] more, for
[seaside / mountain / family] hotels.

Please read the attached brief: what you decide, what is fixed, every block with its content,
the deliverables (section 4) and the checklist before handover (section 5). The design rules
and the token files of our current templates are attached too, with screenshots of real hotel
content in each template.

You do not need to write code: we implement the design and test it (contrast, mobile,
accessibility) ourselves, then send you screenshots to review.

Budget: [...]. Deadline: [...]. Questions welcome before you start.

[Your name]
```
