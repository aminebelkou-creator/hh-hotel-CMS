# Skills

EdgeOne Makers skills are vendored here by `scripts/setup.*`:

    npx skills add TencentEdgeOne/edgeone-makers-tools

Source: https://github.com/TencentEdgeOne/edgeone-makers-tools

Skills installed: makers-agents, makers-edge-functions, makers-cloud-functions, makers-storage, makers-middleware, makers-deploy, makers-cli, makers-recipes.

Project-specific skills (isolation testing, release pipeline, hotel pack authoring) will be added alongside them as they are written.
